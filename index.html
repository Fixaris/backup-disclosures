Fixaris backup

Fixaris backup is a private backup utility operated by Carl for Fixaris. It uses restic and rclone to back up selected Fixaris databases and operational files to the operator’s Google Drive.

Restic encrypts backup content before upload. The utility requests drive.file access to create and manage its own backup files and folders.

This utility is for the operator’s private use and does not offer public registration.
