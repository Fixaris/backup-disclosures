Fixaris backup privacy policy

Effective date: 2 October 2026. This policy applies to the private Fixaris backup utility operated by Carl.

Data and purpose

This utility uses Google authorization to store, retrieve and manage encrypted backups and the Drive file metadata needed for those operations.

Backup content includes Fixaris application and diagnostic database records, configuration and credential files, recovery keys, and source manifests and journals.

Storage and use

Restic encrypts backup content before upload. OAuth credentials are stored on the operator-controlled backup host and used to authenticate with Google. Google Drive hosts the encrypted repository.

This backup utility does not sell Google user data or use it for advertising or AI training.

Revocation and deletion

The operator can revoke its access in Google Account settings. Revoking access does not delete existing backups; the operator can separately delete the backup repository in Google Drive.
